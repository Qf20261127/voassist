旁白 Pro（VoAssist）更新日志
==================================================

v1.0.0 build 34（2026-11-27）
- 修无声：语音扩展进程里 AVAudioSession 激活一律失败（OSStatus 4099），而合成器又被设成「使用应用会话」，
  于是 write 一次回调都不来（日志里 first audio after none、0 samples）
- 默认改为「不用应用会话、不激活」，把会话交给合成器自建
- App 新增「合成音频会话（排错用）」开关，可切 4 种组合对照（0 应用会话+激活 / 1 都不用 / 2 应用会话不激活 / 3 不用会话仍激活）
- App 日志区新增「检查语音扩展（自检）」按钮，直接驱动扩展出一条语音并报结果（可当场判断扩展能否出声）
- 日志细化：setCategory / setActive 分开记录 OSStatus；合成器建立时记 audio session mode；
  write 首次回调记耗时与线程；一次请求 0 回调时记「write gave nothing: 0 buffers …」
- 未变：组件 subtype VoAs、Bundle ID、方案文件格式；显示名仍为旁白 Pro

v1.0.0 build 32（2026-11-27）
- 应用显示名：旁白助手 → 旁白 Pro（桌面图标）
- 系统语音列表显示名：旁白助手语音 → 旁白 Pro 语音
- 语音组件注册名：旁白助手: 旁白助手 → 旁白 Pro: 旁白 Pro
- 方案文件类型名称：旁白助手方案 → 旁白 Pro 方案（扩展名 .voassist 不变）
- App 内导航标题、分享文案、导出日志文件名统一为「旁白 Pro」
- Bundle ID 未变（com.zdyi.voassist / com.zdyi.voassist.voice），可覆盖安装
